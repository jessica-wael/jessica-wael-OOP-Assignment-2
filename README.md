📌 Project Overview

OOP Assignment 2 is a set of four C# projects covering the Single Responsibility Principle, creational design patterns, class inheritance, and a LeetCode problem.

SRP refactor: splitting 10 classes that each had too many responsibilities.
Creational patterns: Singleton, Prototype, and Builder, each applied to a concrete problem.
Library System: a console application modeling members, staff, library items, and loans through an inheritance hierarchy.
LeetCode 1456: Maximum Number of Vowels in a Substring, solved with a sliding window.
